## Official Update 1.0.8 Facts (Steam only)

Source:
https://steamcommunity.com/games/4026250/announcements/detail/689767689898427431
Published: Sep 4, 2026

- Safer / longer main loading that should not crash entire machines
- Anomaly workbench (Cauldron) quality system:
  - 3 same products → lesser / lower-quality Anomaly
  - 2 different products (3 total) → normal-quality Anomaly
  - one of each → enhanced-quality Anomaly
- Mining upgrade now needs only 3 ores per upgrade instead of all 5
- Spring Pads more reliable / more similar outcomes
- Upgrade Terminal wide-text UI fix
- Pistons movable; objects stuck to head follow; pickable again
- Keypad interaction fix
