## Direct Answer

END? is the game’s Secret Ending route name tied to a specific late-game progression. To reach it you must follow the full progression chain (camera/surveillance → upper exploration → Mystery Boxes → 3 Fuses → 200kg → Percentage Pipe → later minigame/production steps → UV-related clues → elevator access/keycard → save‑specific four-digit keypad → Secret Ending route). The four-digit keypad is determined by UV clues in your own save and must be entered in the production-machine unlock order (Duck → Cash Register → Piñata → Anomaly). Do not expect a single community code to work for every save.

## Full Explanation
The Secret Ending labeled END? is gated behind a chain of content that combines exploration, puzzle steps, production-machine activity, and a UV-based clue system. Community findings on full release show the crucial keypad code is save-specific: UV clues in your playthrough reveal four separate digits, and those digits map to the four production machines. To trigger the Secret Ending you must both finish the Keycard/elevator prerequisites and use the digits discovered in your own save.

Because the code is derived from UV clues tied to a save and to machine order, pasted or shared codes from other players will often fail. Some community posts shared numbers like 2640 from individual playthroughs; that may have worked for that specific save but is not a reliable universal solution. If you reach the keypad and it refuses input, that usually indicates a missing prerequisite (Keycard, UV readouts, or an incomplete production/minigame step), not a mysterious one-off bug.

## Common Mistakes
- Searching the internet for a “universal” elevator code instead of reading UV in your save.
- Skipping or misunderstanding the Keycard steps that enable keypad access.
- Entering digits in the wrong order (the digits map to Duck → Cash Register → Piñata → Anomaly).
- Assuming END? is the same as older “END!” ordering or following outdated walkthroughs.
- Brute-forcing codes without re-checking the earlier progression stages.

Q: Why can’t I use the keypad yet?
