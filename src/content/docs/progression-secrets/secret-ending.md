## Direct Answer

END? is the game’s Secret Ending route name tied to a specific late-game progression. To reach it you must follow the full progression chain (camera/surveillance → upper exploration → Mystery Boxes → 3 Fuses → 200kg → Percentage Pipe → later minigame/production steps → UV-related clues → elevator access/keycard → save‑specific four-digit keypad → Secret Ending route). Do not expect a single community code to work for every save.
